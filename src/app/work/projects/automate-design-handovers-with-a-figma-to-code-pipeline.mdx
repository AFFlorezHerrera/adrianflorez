# 🧪 Expansión Estratégica de BIOGENESYS 

## 📌 Descripción del Proyecto
Este proyecto analiza la **expansión estratégica de Biogenesys** en Latinoamérica en el contexto postpandemia del COVID-19.  
Se emplearon herramientas de **Data Analytics** en Python (Pandas, Numpy, Seaborn, Matplotlib) y su integración con **Power BI** para evaluar indicadores sanitarios, demográficos y ambientales.  

El objetivo principal fue identificar **países con mayor potencial** para la instalación de laboratorios y centros logísticos, considerando factores como incidencia, mortalidad, condiciones climáticas y desarrollo socioeconómico.  

---

## 🎯 Objetivos
- Analizar datos de COVID-19 en países de Latinoamérica (Argentina, Brasil, Chile, Colombia, México, Perú).  
- Identificar tendencias temporales y geográficas.  
- Evaluar correlaciones entre variables sanitarias, demográficas y ambientales.  
- Proponer países estratégicos para la expansión de Biogenesys.

## 📂 Dataset
Columnas principales utilizadas:
- `Date`, `country_name`, `population`, `cumulative_confirmed`, `cumulative_deceased`, `human_development_index`, `average_temperature_celsius`, entre otras.  

> 🔎 Se descartaron columnas con más del 60% de datos nulos (ej. densidad poblacional, dosis de vacunas administradas, médicos, enfermeras, etc.).

---

## 📈 Principales Hallazgos
- 🇨🇴 **Colombia**: Mayor incidencia acumulada por cada 100.000 habitantes.  
- 🇵🇪 **Perú**: Mayor número de muertes acumuladas.  
- 🇲🇽 **México**: Alta mortalidad y casos acumulados, con políticas que lograron reducir contagios en 2021.  
- 🌡️ La **temperatura promedio** mostró correlaciones débiles con la incidencia, sugiriendo que el clima no es un factor determinante.  
- 📊 El **Índice de Desarrollo Humano** se relaciona con menor mortalidad relativa, reflejando acceso desigual a sistemas de salud.  

---

## 📊 Visualizaciones
Algunas gráficas incluidas:
- Histogramas de incidencia acumulada.  
- Boxplots de temperatura por país.  
- Series temporales de casos y muertes.  
- Matriz de correlación entre indicadores demográficos y sanitarios.  
- Dashboards interactivos en Power BI.  

---

## 🚀 Conclusiones
- **Colombia, Perú y México** son los países más estratégicos para iniciar la expansión de Biogenesys.  
- La **normalización de datos** permitió comparar tendencias entre países con poblaciones muy diferentes.  
- La coordinación regional es clave para enfrentar futuras pandemias.
